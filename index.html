About these suggestions. They are estimates based only on what you entered — household size, income, and where you live. They don't guarantee eligibility, and they don't affect your application to this listing in any way.

Doorway's listing range reflects the programs behind it: tax-credit (LIHTC) units are capped at 60% AMI (up to 80% under income averaging), inclusionary and density-bonus units can reach moderate income, and minimum-income rules at each property set effective floors near 30%. Coordinated Entry eligibility is based on housing status, not income; 30% AMI is used here as the routing threshold.

Income limits use the 2026 State Income Limits (HCD, revised June 2026, from HUD's FY2026 release). AMI figures change every year — reconfirm at each annual update.

Manage Resources

Keep the library current: scan the authoritative sources, add or replace documents, and edit any resource card directly. Eligibility rules behind each resource are preserved through edits so matching keeps working.

Scan sources for new & updated resources

Checks the library's authoritative domains — osh.santaclaracounty.gov, scc.bitfocus.com, scchousingauthority.org, hudexchange.info — for documents that are new or newer than what's on file. Every finding requires human approval before it touches the library; nothing publishes automatically. Simulated at Level 1. In production this runs as a scheduled crawler with an AI summarizer over these domains only — AI drafts the finding, a person approves it, and the routing rules themselves stay untouched.

Add or update a resource

Upload program documentation (PDF, Word, image) and it joins the library immediately. If you upload a revised version of an existing resource, choose “Replace existing” and the system updates it in place — eligibility tags are preserved, so matching keeps working. Uploads live in this browser session only (Level 1); production persists them to the shared library.

Edit existing resources

Every card in the library. Edits change the name, category, description, or link — the eligibility rules stay intact.
